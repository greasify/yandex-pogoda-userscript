# Яндекс Погода: Идёт дождь?

На странице карты осадков каждые 10 минут отвечает «Да» или «Нет», есть ли дождь на точке.

## Установка

Для работа нужно установить расширение [Tampermonkey](https://www.tampermonkey.net/).

Открой ссылку и подтверди установку:
> [yandex-pogoda.user.js](https://greasify.github.io/yandex-pogoda-userscript/yandex-pogoda.user.js)

## Разработка

```sh
pnpm install
pnpm dev
```
